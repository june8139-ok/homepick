# DB 설계 v1.0

## 1. apartments

단지 기본 정보를 저장한다.

| 필드 | 설명 |
|---|---|
| id | 단지 고유 ID |
| name | 단지명 |
| type | 아파트 / 오피스텔 / 상가 |
| region | 시·도 |
| city | 시·군·구 |
| address | 상세 주소 |
| builder | 시공사 |
| developer | 시행사 |
| total_units | 총 세대수 |
| floors | 층수 |
| move_in_date | 입주 예정일 |
| sale_status | 청약중 / 선착순 / 분양중 / 분양완료 |
| min_price | 최저 분양가 |
| max_price | 최고 분양가 |
| parking_ratio | 세대당 주차대수 |
| summary | 단지 한줄 설명 |
| created_at | 등록일 |
| updated_at | 수정일 |

| 필드 | 설명 |
|---|---|
| id | 계약조건 ID |

| interest_free | 중도금 무이자 여부 |
| cashback | 계약축하금 / 페이백 |
| free_options | 무상옵션 |
| transfer_allowed | 전매 가능 여부 |
| balance_delay | 잔금 유예 |
| tax_support | 취득세 지원 |
| valid_from | 적용 시작일 |
| valid_to | 적용 종료일 |
| change_note | 변경 내용 |
| created_at | 등록일 |
